ติดตั้งเสร็จเรียบร้อย

วิธีใช้งาน:
1. สร้าง shortcut บน Desktop หรือ Start Menu แล้วดับเบิลคลิกเพื่อเปิดโปรแกรม
2. เลือกไฟล์ C3D (File > Load C3D...)
3. (ถ้ามี) โหลดวิดีโอ front/side view
4. เลือกแบบทดสอบ (Single Leg Squat หรือ Single Leg Hop)
5. เลือกการประเมินและกด Run

หมายเหตุ:
- โปรแกรมต้องอยู่ในโฟลเดอร์ที่ติดตั้ง พร้อมไฟล์ประกอบทั้งหมด
- ไม่ต้องติดตั้ง Python แยกต่างหาก โปรแกรมมี runtime อยู่ในตัวแล้ว

กด Finish เพื่อปิดตัวติดตั้ง
